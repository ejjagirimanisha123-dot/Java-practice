# Smart Street Lighting System

A Java-based simulation of an intelligent street lighting system designed to optimize energy consumption by controlling lights based on ambient light levels and motion detection.

## 📋 Project Overview
This system demonstrates how automated infrastructure can reduce power waste. The program simulates sensors (light intensity and motion) to determine whether street lights should be `ON` or `OFF`.

## 🚀 Key Features
* **Ambient Light Sensing:** Automatically activates lights when it gets dark.
* **Motion Detection:** Brightens or activates lights only when movement is detected to save energy during low-traffic hours.
* **Object-Oriented Design:** Implemented using Java classes to represent the system logic.
